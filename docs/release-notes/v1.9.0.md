### Score impact

- Not comparable with 1.8.0: verdicts move both ways. On the saved public predictions of the 27 published systems (dataset snapshot 1045c42), 2,000 of 439,761 verdicts change (0.45%): 1,163 pass to fail and 837 fail to pass, in 499 of the 16,288 tests.
- By test type (pass to fail / fail to pass): `present` 428 / 767, `order` 384 / 0, `table_cell` 351 / 70. Layout and `repeat` are unchanged.
- Per system: headline -0.50 to +0.10 points (median -0.05), text -0.33 to +0.39, tables -1.84 to 0.00, layout unchanged. Ranks change only between neighbours (ranks 9 to 14).
- The README leaderboard is not regraded in this release; it stays on 1.8.0.

### What changed

- **Numbers are exact everywhere.** `present`, `order` and `table_cell` keep every number whole at any edit budget, including its sign, decimal point, thousands separator and exponent (`18.12` no longer passes for `18.55`).
- **Equations read as printed.** Marks a reader cannot tell apart compare equal (transpose forms, `\bar` and `\overline`, doubled bars and brackets); LaTeX symbols the text view dropped now read as their characters (`$\neg p$` reads `¬p`).
- **Tables.** A neighbour matches by one of its `<br>` lines, beside by the aligned line and above or below by the touching line, so a datasheet cell that stacks two rows' values is read correctly. A section label repeated in every cell reads as a section row.
- **Negative tests need an output.** `present` with `{"absent": true}`, `no_excess_repeats` and `layout_absent` fail an empty output unless the page's gold holds a `page_near_empty` test.
- **Fold.** `◼` and a bare `√` read as checked boxes; a vulgar fraction after a digit is set apart (`1½` reads `1 1/2`); a raised decimal point reads as `.`.
- **Fixed.** Deeply nested math no longer crashes the scorer; an empty LLM reply is an empty page, and a provider safety block is a per-page refusal.

### New test types and settings

- `verbatim`: the exact text between two anchors.
- `no_excess_repeats`: no run of 16 words is written more often than the page prints it.
- `layout_absent`: a blank page has no block of the listed kinds.
- `present` settings `{"absent": true}` (a known wrong reading is not in the output) and `{"blank_after": true}` (a form field is left blank); `table_cell` args `{"empty": true}` and `{"end": true}`.

None of these is used by a published test yet, so they move no published verdict.
