## Reader change and selection

The shared LLM reader accepts `bbox` alongside `bbox_2d` and `box_2d`, including its
malformed-JSON fallback. All three use the prompted `[ymin, xmin, ymax, xmax]` coordinates
on a 0–1,000 grid. Key precedence and the union of nested boxes are preserved. No
coordinate order is guessed, and no model-specific processing, prompts, gold data or
scoring functions were changed.

All 172 original Argon failures and all 189 original Carbon failures were rerun once.
Argon recovered 164; Carbon recovered 178. Original successful outputs and score lines
were retained unchanged. Remaining Argon failures are eight provider safety refusals.
Carbon has four safety refusals, one recitation refusal, five output-token-limit failures,
and one response with no usable blocks. Refusals are classified from provider finish
metadata, rather than text transcribed from the document.

Other historical leaderboard rows have not been rerun with this alias. The existing
price and latency charts predate these Gemini 4 measurements. No fresh full pass with
the updated reader and no repeated-run variance study was performed; the small difference
between the two models is not evidence of a statistically significant ranking.

## Reproduce

From this checkout, with `uv` installed, first validate a five-page plan without model calls:

```bash
uv run --script scripts/reproduce_gemini4.py google/gemini-4-argon --plan
```

Set `OPENROUTER_API_KEY` in your environment for prediction. The default performs a
five-page smoke run; `--full` selects all 2,937 pages. The script requests confirmation
before paid calls (`--yes` supplies it noninteractively):

```bash
uv run --script scripts/reproduce_gemini4.py google/gemini-4-argon --full
uv run --script scripts/reproduce_gemini4.py google/gemini-4-carbon --full
```

The script installs the pinned published scorer in an isolated script environment,
performs the original stock pass, then reruns every failed page with only the reader
function from this checkout. It writes a derived full summary without rewriting either
run's artifacts. Repeating this stochastic protocol may produce different scores and costs.
