Generated by `PYTHONPATH=. uv run python tests/metamorphic/render_certificate.py --write`; do not edit by hand. How to read it: [README.md](README.md).

A register of 68 relations its authors selected, not every relation of the scorer (see 'Not covered' in the README): 59 hold, 9 deviate (4 of them, M1a, M1b, M1c, M1e, are about folding a string twice, which the scorer never does and no document promises, so they change no score). HOLDS means no counterexample in the sampled examples, nor, when OPB_DATASET is set, in the checks over every real test of the published dataset at revision d70182b. It is not a proof.

- Each Hypothesis test tries at most 300 examples in CI (5,000 in the deep profile, which CI does not run). It tries fewer when its input space runs out; the evidence column then gives the count.
- CI does not set OPB_DATASET, so it skips every check over real tests. The real-test counts below are constants in the source, from runs with the dataset set, and are checked only when it is set.
- `--run` reports a row as passed from the checks it ran, and says how many it skipped.
- Effects on scores marked 'Measured on cached leaderboard re-runs' cannot be re-run from this package.
- A deviation whose effect is 'unknown' is one that could change a score: treat it as open.
